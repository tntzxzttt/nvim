# Git

**LazyVim extra:** `lazyvim.plugins.extras.lang.git`

## Tooling

| Category  | Tool | Managed by |
| --------- | ---- | ---------- |
| LSP       | —    | —          |
| Formatter | —    | —          |
| Linter    | —    | —          |

Provides Treesitter highlighting for git-related filetypes (commit messages,
diffs, rebases) and `cmp-git` for commit/issue completions.

## External Dependencies

| Dependency | Install            |
| ---------- | ------------------ |
| Git        | `brew install git` |

Git is almost certainly already installed on your system.
